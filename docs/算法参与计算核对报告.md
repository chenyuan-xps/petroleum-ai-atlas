## 2 每个案例的实际算法与闭环

### 2.1 co1 完井方式智能优选
- **算法**：TOPSIS（向量归一化 → 加权 → 正/负理想解 → 相对贴近度）。附：权重 ±25% 扰动 10 组做稳定性检验。
- **核心函数**：`topsis()`（L97）、`evaluate()`（L74）、`perturbList()`（L139）。
- **进入算法的输入**：渗透率、地层压力、出砂风险、预算、目标日产、决策偏好。
- **读取算法输出的图表**：`renderRadar`（五项指标）、`renderBar`（贴近度排序）、`renderReasons`（加权贡献分解）、`renderStress`（10 组扰动）、`renderKpis`、`renderTable`。
- **经验 vs 智能**：经验方案固定为射孔完井，与推荐方案取自**同一次** `evaluate()` 的 `rows`，共用同一套指标与参数。
- **适用边界**：指标打分是规则映射，未经试采/邻井标定；TOPSIS 只回答"当前权重下谁更接近理想解"。

### 2.2 co2 射孔参数智能设计
- **算法**：产能代理模型 `calc()` + 四维网格搜索（6 相位 × 9 孔径 × 21 孔密 × 19 段长 ≈ 2.1 万组），带风险阈值约束。
- **核心函数**：`calc()`（L50）、`optimize()`（L72）、`surface()`（L110）。
- **输入**：孔密、相位、孔径、段长、地层压力、搜索口径（综合最优 / 极限产能 / 最低风险）。
- **图表**：`renderHeat`（`res.gridQ` 来自 `surface(state,'q')` 实时计算）、`renderRisk`（风险等高线 + 不可行区）、`renderPhase`、`renderScanN`、`renderOutput`。
- **经验 vs 智能**：`base = calc(EXPERIENCE…)` 与 `opt` 同为一次 `renderAll` 内的结果。
- **无可行解**：`opt.feasible === false` 时输出卡标「超阈值」，note 写「无可行解：所有组合超阈值，模型退回风险最小方案」。

### 2.3 co3 完井管柱受力分析
- **算法**：一维逐段积分（自重、摩阻、狗腿附加曲率）→ 轴向 + 弯曲应力 → 安全系数；滑动平均残差做异常检测；37 档速度扫描（本轮修完改为读 `opt.scanned`）。
- **核心函数**：`buildProfile()`（L52）、`summarize()`（L81）、`scanSpeed()`（L120）。
- **输入**：井深、井斜、摩阻系数、管柱线重、下入速度。
- **图表**：`renderTrajectory`、`renderForce`（钩载沿井深）、`renderSafety`（安全系数 + 风险带）、`renderScan`（速度-安全窗口）、`renderDepth`。
- **本轮修复**：扫描不到可行档位时，推荐卡改标「参考解 · 不满足安全窗口」，note 指出「37 档全部越界——最接近的一档仍以最小安全系数 / 钩载下限 / 钩载上限卡住」。

### 2.4 co4 智能完井滑套控制
- **算法**：分层产能模型 `rates()`（产油 u^0.85、产水 u^1.25·水油比）+ 每轮 21³=9261 组开度枚举 + 约束（产油目标、含水上限、液量上限）+ 每 7 天滚动重算。
- **核心函数**：`rates()`（L57）、`optimizeOpen()`（L77）、`simulate()`（L106）。
- **输入**：三层初始开度、目标产油、含水上限、调控周期。
- **图表**：`renderOpenChart`、`lineChart`（产油/含水逐日）、`renderStack`（分层产液）、`renderSplit`（AI vs 固定）、`renderStrip`、`renderLoop`。
- **经验 vs 智能**：固定开度 = `simulate(fixed,'manual')`，AI = `simulate(fixed,'ai')`，两条曲线同一次模拟、同一套 `rates()`。
- **本轮修复**：`planOk=false` 时红条写明「9261 组里没有一组能达标，缺口来自液量上限 270 t/d 与各层最大产能」，并说明显示的是缺口最小的参考组合。

### 2.5 e1 压裂参数智能优化
- **算法**：裂缝代理模型（净压力、摩阻、液效率随泵注时长折减）+ 三维搜索（排量 2–8、液量 200–1200、砂比 5–30 ≈ 2.6 万组）+ 压力/砂堵双约束。
- **核心函数**：`evalFrac()`（L57）、`optimize()`（L103）、`surfaceOpt()`（L138）。
- **图表**：`renderHeat`（增产热力图）、`renderRisk`（风险等高线，不可行区灰化）、`renderPressure`（泵注压力曲线）、`renderTornado`（因素敏感性）、`renderTime`。
- **经验 vs 智能**：`exp = evalFrac(EXPERIENCE…)` 与 `opt` 同一模型、同一闭合压力。
- **本轮修复**：无可行解时区分「压力越界 / 砂堵越界 / 两者同时越界」，并给出组合数。

### 2.6 pr2 产量智能预测
- **算法**：指数递减 `q0·e^(-d·t)` + 注水（影响递减率）+ 油嘴（产能倍数）+ 含水耦合（液量上限压制产油）；制度搜索 17×17=289 组；区间按 `√(天/周期)` 展宽。
- **核心函数**：`forecast()`（L62）、`optimize()`（L96）、`factorsOf()`（L154）、`bandAt()`（L133）、`fitR2()`（L117，本轮新增）。
- **图表**：`renderForecast`（逐日 `bandAt(p.day)` 画上下界，不是固定宽度）、`renderScenario`、`renderFactors`（每项 +10% 重算得的敏感度排序）、`renderOutput`。
- **本轮修复**：历史拟合 R² 由 `fitR2()` 按残差计算，当前 **0.682**——比原来写死的 0.94 低，这是真实值。

### 2.7 s3 初至波自动拾取
- **算法**：STA(8)/LTA(60) 能量比 + 阈值首峰触发；对比固定阈值 3.0 的"经验拾取"。
- **核心函数**：`energyRatio()`（L52）、`pick()`（L64）、`fillCompare()`（L82）。
- **图表**：上幅原始波形 + 真值线，下幅 STA/LTA 比值 + 阈值线；改噪声或阈值，两条曲线与拾取位置同步变化。

## 7 答辩时怎么证明「不是只加了文字」

被问"你的智能方法真的在算吗"，按这个顺序答：

1. 打开任一案例，先指方法卡最下面那行**本轮中间量**：「这 5 个数是刚才那次刷新的返回值，不是写死的。」
2. 拖一个滑杆，让老师看这一行数字和旁边图表**同时**变化。
3. 再指经验方案那一列：「它和推荐方案来自同一次计算，只是换了参数。」
4. 最后补一句边界：「这是合成数据上的参数化代理模型，不是训练出来的深度网络，所以结论只能做筛查。」
